# Roteiro interno de teste humano do quiz

Este roteiro deve ser aplicado fora do site público. Não deve coletar nome, e-mail, telefone, imagem, informação médica ou qualquer outro dado pessoal dentro do quiz.

## Preparação

1. Entregar a versão publicável do quiz sem explicar previamente como a pontuação funciona.
2. Pedir que a pessoa percorra o fluxo em dispositivo próprio ou ambiente de teste.
3. Não conduzir respostas e não apresentar produtos, kits, preços ou checkout durante o teste.
4. Registrar apenas observações agregadas e anônimas em documento interno aprovado para pesquisa.

## Perguntas após o fluxo

1. Você conseguiu prever o resultado antes do final?
2. Alguma pergunta pareceu repetida?
3. O perfil final pareceu compatível com suas respostas?
4. O quiz pareceu uma tentativa de empurrar uma compra?
5. Ficou claro que não era diagnóstico?

## Pontos de observação

- Verificar menções espontâneas às perguntas 2, 4 e 5.
- Identificar se a pessoa percebe repetição entre duração, organização de compras e continuidade.
- Confirmar se o aviso de privacidade e a natureza não diagnóstica foram compreendidos.
- Registrar qualquer expectativa de kit, preço, tratamento ou resultado criada pelo fluxo.
- Não alterar perguntas automaticamente: consolidar os achados e submeter uma revisão editorial separada.
